# KidsTechEdu - 少儿未来素质教育平台

## 项目简介

KidsTechEdu（未来星学堂）是一个面向4-12岁儿童的素质教育互联网平台，旨在帮助儿童适应未来科技社会的需求。

## 目标用户

- 4-12岁儿童（主要学习用户）
- 儿童家长/监护人
- 教师内容创作者

## 核心教育领域

- **AI与编程思维**：AI基础认知、编程启蒙与进阶
- **英语学习**：从启蒙到进阶的全年龄段英语教育
- **历史与文化**：中国历史、世界历史、文化传承
- **逻辑思维训练**：思维启蒙、数学思维、逻辑推理
- **科学探索**：科学启蒙、基础科学、实验实践
